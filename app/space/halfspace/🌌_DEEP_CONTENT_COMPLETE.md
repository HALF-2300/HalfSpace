For **real-time data** (not just fallback):

1. Get free key: https://api.nasa.gov/
2. Create `.env.local`:
   ```
   NEXT_PUBLIC_NASA_API_KEY=your_key_here
   ```
3. Restart server

Without this, it uses demo data (which still looks great).
