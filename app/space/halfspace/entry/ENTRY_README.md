# 🌌 HalfSpace Entry Portal — البوابة السينمائية

## ✨ ما تم بناؤه

واجهة دخول سينمائية مذهلة لـ HalfSpace تأخذ المستخدم في رحلة تدريجية من **العدم** إلى **الكون الكامل**.

---

## 🎬 المراحل (Phases)

### 1. **Void** (الفراغ) — ثانيتان
- شاشة سوداء صامتة
- سكون مطلق
- تمهيد للولادة

### 2. **Awakening** (الصحوة) — 4 ثوان
- ضوء صغير يظهر في المركز
- يتمدد ببطء
- حلقات نبض تتوسع
- النجوم تبدأ بالتحرك ببطء

### 3. **Manifest** (التجلي) — 4 ثوان
- العنوان يظهر: **HalfSpace**
- العبارة العربية: "انظر إلى الكون كما لو كان ينظر إليك"
- العبارة الإنجليزية: "Look at the universe as if it's looking back at you"
- النجوم تتسارع

### 4. **Ready** (الجاهزية)
- زر الدخول يظهر: "ادخل الفضاء"
- جزيئات طافية في الخلفية
- تلميح التمرير في الأسفل
- جاهز للانتقال

---

## 🎨 المميزات البصرية

### حقل النجوم ثلاثي الأبعاد
```javascript
- 800 نجمة
- محاكاة عمق ثلاثية الأبعاد
- سرعة متغيرة حسب المرحلة
- مسارات حركة للنجوم السريعة
- تأثير tunnel/warp drive
```

### الضوء المركزي المتمدد
- يبدأ من نقطة صغيرة (10px)
- يتمدد إلى 800px
- تدرج لوني من الأبيض إلى الأزرق
- يتلاشى تدريجياً

### نبضات الصحوة
- 3 حلقات متتالية
- تتوسع من المركز
- تتلاشى مع الاتساع
- توقيت متأخر لكل حلقة

### العنوان المتدرج
```css
Half → تدرج بنفسجي/أرجواني
Space → تدرج أزرق سماوي
```

### زر الدخول التفاعلي
- حدود متوهجة
- تأثير موجة عند hover
- ارتفاع عند hover
- توهج مكثف عند click

```typescript
useState → void | awakening | manifest | ready
useEffect → timers للانتقال بين المراحل
```

#### Audio Control
```typescript
- auto-play عند click
- loop للتشغيل المستمر
- ref للتحكم programmatic
```

## 🎯 تدفق التجربة

```
المستخدم يفتح الصفحة
    ↓
شاشة سوداء (2 ثانية)
    ↓
ضوء يتمدد + نبضات (4 ثوان)
    ↓
العنوان يظهر (4 ثوان)
    ↓
زر الدخول يظهر
    ↓
المستخدم ينقر "ادخل الفضاء"
    ↓
انتقال سلس إلى /space/halfspace
    ↓
التجربة الكاملة تبدأ
```

## 🎨 التخصيص

### تغيير الألوان
```css
/* في entry.css */
.title-half {
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}

.title-space {
  background: linear-gradient(135deg, #4facfe 0%, #00f2fe 100%);
}
```

### تعديل السرعات
```typescript
// في page.tsx
const timer1 = setTimeout(() => setPhase('awakening'), 2000); // Void
const timer2 = setTimeout(() => setPhase('manifest'), 6000);   // Awakening
const timer3 = setTimeout(() => setPhase('ready'), 10000);     // Manifest
```

### تغيير عدد النجوم
```typescript
const numStars = 800; // زد أو أنقص حسب الأداء
```
