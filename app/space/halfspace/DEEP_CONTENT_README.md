## 📡 NASA Data Integration

### Automatic Updates
The Live Data Feed pulls real information from:

1. **NASA Exoplanet Archive**
   - API: `exoplanetarchive.ipac.caltech.edu`
   - Updates: Daily
   - Data: Confirmed planets, habitable candidates

2. **LIGO Gravitational Waves**
   - Source: LIGO Open Science Center
   - Updates: Continuous during observing runs
   - Data: Black hole mergers, neutron star collisions

3. **Near-Earth Objects**
   - API: NASA NEO API
   - Updates: Real-time
   - Data: Asteroids passing near Earth today

4. **James Webb (Manual Updates)**
   - Currently using static data
   - Can be automated with JWST MAST API

### API Key Setup
To enable real NASA data (not just fallback data):

1. Get a free API key: https://api.nasa.gov/
2. Add to your environment:
   ```bash
   NEXT_PUBLIC_NASA_API_KEY=your_key_here
   ```
3. Restart the dev server

Without a key, it uses `DEMO_KEY` with rate limits.

## 🌟 Best Practices for Content

### Writing Guidelines
1. **Hook first** — Tagline must grab attention in 5 words
2. **Summary next** — One paragraph, no jargon
3. **Deep dive** — Multiple sections, expandable
4. **End with mystery** — Questions, not answers

### Tone
- **Conversational but not casual** — "You" is okay, "ur" is not
- **Wonder but not mystical** — Awe from reality, not woo
- **Honest about limits** — "We don't know" is powerful
- **No condescension** — Explain without talking down

### Visual Hierarchy
1. **Title** — Gradient, large, eye-catching
2. **Tagline** — Italic, provocative
3. **Summary** — Highlighted box
4. **Sections** — Collapsible, organized
5. **Questions** — Special styling, memorable
