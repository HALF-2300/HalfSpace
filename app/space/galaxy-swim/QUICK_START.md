# Galaxy Swim — Quick Start Guide

## 🚀 تشغيل التجربة

### الطريقة الأسرع
```bash
npm run dev
```

ثم افتح المتصفح على:
```
http://localhost:3000/space/galaxy-swim
```

---

## 🎮 التحكم السريع

### وضع Auto Cruise (التلقائي)
- يبدأ تلقائياً عند فتح الصفحة
- الكاميرا تدور حول المجرة سينمائياً
- للتبديل لوضع Free Swim: اضغط زر "🎮 Free Swim"

### وضع Free Swim (الحر)
- **WASD** - التحرك (أمام/يسار/خلف/يمين)
- **Q/E** - صعود/نزول
- **Shift** - تسريع الحركة
- **Mouse Drag** - تدوير الكاميرا

### أدوات التنقل
- **🎯 Re-center** - العودة للموقع الابتدائي
- **⚡ Teleport** - الانتقال السريع لمواقع محددة
- **🔬 Science Mode** - تفعيل المحتوى العلمي

---

## 📊 إعدادات الجودة

| الجودة | عدد النجوم | الأجهزة المناسبة |
|--------|-----------|------------------|
| Low | 50,000 | الموبايل والأجهزة القديمة |
| Medium | 150,000 | اللابتوب العادي (افتراضي) |
| High | 300,000 | أجهزة الألعاب |
| Ultra | 500,000 | الأجهزة العالية جداً |

**ملاحظة:** النظام يخفض الجودة تلقائياً إذا انخفضت السرعة (FPS < 30 لمدة 5 ثوان)

## 🎯 نقاط الاهتمام

طِر نحو هذه المواقع لرؤية بطاقات المعلومات:

1. **Galactic Core** (0, 0, 0) - مركز المجرة والثقب الأسود
2. **Spiral Arm** (400, 20, 300) - الأذرع الحلزونية
3. **Nebula Region** (-300, 50, 400) - سحب السديم
4. **Black Hole** (0, -10, 0) - الثقب الأسود المركزي
5. **Galactic Halo** (600, 100, -500) - الهالة الخارجية
6. **Dust Lane** (200, 0, -300) - ممرات الغبار

## ⚙️ استكشاف الأخطاء

### الشاشة فارغة؟
- تأكد أن المتصفح يدعم WebGL: https://get.webgl.org/
- جرّب متصفح آخر (Chrome/Firefox)
- تحقق من console للأخطاء

### الأداء بطيء؟
- خفّض الجودة من القائمة
- أغلق التابات الأخرى
- النظام سيخفض الجودة تلقائياً

### التحكم لا يعمل؟
- تأكد أن الصفحة لها focus (اضغط عليها)
- جرّب F5 لإعادة التحميل

---

## 📱 الدعم

- **WebGL**: مطلوب للتجربة الكاملة
- **Fallback**: Canvas 2D إذا WebGL غير متاح
- **المتصفحات**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+

## 💡 نصائح للاستمتاع الأمثل

1. ابدأ بـ **Auto Cruise** لتأخذ جولة سينمائية
2. ثم جرّب **Free Swim** للاستكشاف
3. فعّل **Science Mode** للتعلم
4. اقترب من النقاط المثيرة لرؤية البطاقات التعليمية
5. جرّب **Teleport** للانتقال السريع بين المواقع
