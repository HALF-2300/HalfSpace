An immersive, cinematic, and interactive space exploration website with 25+ pages covering everything from our solar system to distant galaxies, black holes, space missions, and the mysteries of the cosmos.

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the **URL printed by Next.js in the terminal**.

- Default port: `http://localhost:9200`
- If `9200` is already in use, Next.js may pick another available port — always trust the printed URL.

### Build

```bash
npm run build
npm start
```
